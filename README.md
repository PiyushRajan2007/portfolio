# 🚀 Premium Developer Portfolio

A modern, responsive, and interactive developer portfolio website built using **HTML, CSS, and JavaScript**. Designed with a premium cyber-inspired aesthetic, smooth animations, particle effects, scroll reveals, and an elegant user experience to showcase projects, skills, achievements, and professional journey.

## ✨ Features

### 🎨 Modern UI/UX

* Premium cyber-inspired dark theme
* Alternate Obsidian Space theme
* Responsive design for desktop, tablet, and mobile
* Smooth transitions and micro-interactions

### 🌌 Interactive Effects

* Canvas particle background animation
* Interactive mouse-responsive glow effects
* Animated card hover effects
* Smooth scroll-based animations

### ⌨️ Dynamic Content

* Typewriter text animation
* Scroll reveal animations using Intersection Observer
* Active navigation scrollspy
* Animated skill and project sections

### 📱 Responsive Navigation

* Desktop navigation menu
* Mobile drawer navigation
* Active section highlighting
* Smooth anchor navigation

### 🌙 Theme Management

* Theme toggle switch
* Local storage theme persistence
* Seamless switching between visual styles

## 🛠️ Tech Stack

* **HTML5**
* **CSS3**
* **JavaScript (ES6+)**
* **Canvas API**
* **Intersection Observer API**
* **Local Storage API**

## 🔧 Setup

1. Clone the repository

```bash
git clone <repository-url>
```

2. Navigate to the project folder

```bash
cd portfolio
```

3. Open `index.html` in your browser or run using VS Code Live Server.
