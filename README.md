# Piyush Rajan Portfolio

A premium, responsive developer portfolio for Piyush Rajan, AI Engineer and Full Stack Developer.

## Experience

- Futuristic AI engineering command-center interface
- Interactive Three.js AI core with a restricted-preview canvas fallback
- GSAP entrance motion and Lenis smooth scrolling
- Live public GitHub profile and repository signal through the GitHub API
- Project filters and accessible case-study dialog
- Interactive Build / Think / Ship skills matrix
- Experience and achievements timeline
- Public LeetCode profile link without fragile scraping
- Portfolio-data assistant for common questions
- Responsive mobile-first layout and reduced-motion support

## Run locally

Open `index.html` directly in a browser or use VS Code Live Server. The visual experience loads Three.js, GSAP, and Lenis from public CDNs. GitHub data requires network access and falls back to curated content when unavailable.

## Structure

- `index.html` — semantic portfolio content and metadata
- `style.css` — responsive visual system and motion styles
- `script.js` — WebGL scene, public GitHub lookup, interaction controls, and assistant
